The 6 AI Agents Working Behind the Scenes

Watcher

Keeps an eye on your Google Drive folder. The moment a new PDF appears, it wakes up the rest of the team.

Reader

Opens the PDF and reads every word — even if it's a scanned image. Handles tables, charts, and messy formatting.

Analyst

Finds what actually matters — key numbers, risks, deadlines, and trends. Ignores the filler.

Writer

Writes a clean, structured summary with sections for exec overview, key points, risks, and action items.

Fact-Checker

Reads the summary and compares it to the original. If anything looks made up, it sends the Writer back to try again.

Messenger

Sends the finished summary to your email or Slack channel. You don't have to check anything — it comes to you.

Dev Mode — Technical Architecture

LangGraph Multi-Agent Pipeline

Stateful graph with eval retry loop · AWS-native · Scalable to 10k PDFs/day

LangGraph State Machine PDFState TypedDict
1
Drive Monitor Agent
EventBridge cron Trigger

Polls Google Drive API every 15 min · dedup check via drive_file_id in RDS · pushes new file IDs to SQS queue

state["new_files"] = drive.list_new(folder_id, since=last_run)
2
Document Processing Agent
AWS Textract Extractor

Downloads PDF from Drive → S3 · Detects if scanned (image-based) → routes to Textract OCR · text-based → PyPDF2 · validates extraction quality · stores raw text in S3

state["raw_text"] = textract.extract(s3_key) if is_scanned else pypdf2.read(s3_key)
3
Analysis Agent
Bedrock Claude 3.5 Analyzer

Chunks text with semantic splitter · embeds via Titan Embed v2 · stores in OpenSearch · identifies key entities, numbers, risks, action items via structured output

state["analysis"] = bedrock.invoke(analysis_prompt, structured_output=AnalysisSchema)
4
Summary Agent
Bedrock Claude 3.5 Generator

Generates structured JSON summary: exec_summary, key_points[], statistics[], risks[], action_items[], important_dates[] · uses analysis state as grounding context

state["summary"] = bedrock.invoke(summary_prompt, output=SummarySchema)
5
Quality / Eval Agent
LangSmith eval Evaluator

Scores summary on faithfulness (0–1) against source text · checks for hallucinations · if score < 0.85 AND retry_count < 3 → loops back to Summary Agent with critique

if eval_score < 0.85 and state["retry_count"] < 3: return "summary_node"
retry → summary_node (max 3x)
6
Notification Agent
AWS SES + Slack Notifier

Saves summary to RDS + embeds into OpenSearch · sends via SES email and/or Slack webhook · updates document status to "completed" · logs to CloudWatch

db.save(summary); ses.send(email, summary); slack.post(webhook, summary)

End-to-End Flow

From PDF upload to summary in your inbox — step by step

1

PDF lands in Google Drive folder

User or automated system drops a PDF into the monitored Drive folder. Nothing else needed.

2

EventBridge fires → Drive Monitor polls → SQS job queued

Cron rule triggers every 15 min. Drive Monitor checks for new files, deduplicates against RDS, pushes new file IDs to SQS. ECS Fargate worker picks up the job.

3

Document Processing Agent extracts text

Downloads PDF to S3. Detects if image-based → AWS Textract OCR. Text-based → PyPDF2. Validates extraction quality. Stores raw text back to S3.

4

Analysis Agent identifies what matters

Chunks text semantically. Embeds via Titan Embed v2 → stores in OpenSearch. Calls Bedrock Claude 3.5 to extract key entities, numbers, risks, action items as structured JSON.

5

Summary Agent writes the structured summary

Uses analysis output as grounding context. Calls Bedrock Claude 3.5 with a structured output schema: exec_summary, key_points, statistics, risks, action_items, important_dates.

6

Quality / Eval Agent scores for hallucinations

Compares summary against source text. Scores faithfulness 0–1. If score < 0.85 and retry_count < 3 → sends critique back to Summary Agent and retries. If score ≥ 0.85 → passes.

Pass ≥ 0.85 → continue Fail < 0.85 → retry (max 3x)
7

Summary saved, notifications sent, dashboard updated

Summary JSON saved to RDS. Embedded into OpenSearch for search. AWS SES sends email. Slack webhook posts to channel. Document status updated to "completed". CloudWatch logs the full trace.
