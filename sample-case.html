End-to-End Data Flow
1

PDF uploaded to Google Drive folder → EventBridge cron fires every 15 min → Drive Monitor Agent polls for new files

2

New file detected → dedup check against RDS → if new, download to S3 → push job to SQS queue

3

ECS Fargate worker picks up SQS job → Doc Processing Agent runs AWS Textract (OCR if scanned) → raw text stored in S3

4

Analysis Agent → Summary Agent → structured JSON summary generated via Bedrock Claude 3.5

5

Quality/Eval Agent scores summary (0–1) against source text → if score < 0.85, loops back to Summary Agent (max 3 retries)

6

Summary saved to RDS + embedded into OpenSearch → Notification Agent sends via SES email + Slack webhook → Dashboard updated
